# Check Roadmap Scope

Read `docs/10-development-roadmap.md` before responding. Identify the relevant phase and milestone, decide whether the request is in scope, partially in scope, or out of scope, and state the milestone acceptance criteria. For out-of-scope work, name the correct phase and whether a stub is acceptable.

Phases: 1 Movement MVP; 2 Combat Core; 3 Vertical Slice; 4 Systems; 5 Content Expansion; 6 1.0 Candidate. Prioritize the phases 0–3 critical path over polish or content expansion unless the user explicitly requests otherwise.
